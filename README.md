# ✅ Todo App

A simple todo app built with React.

🔗 **Live Demo:** [click here](https://karixhma12.github.io/react-todo-app_withlocalstorage/)

## Features
- Add, edit, delete todos
- Mark todos as done
- Persists data with localStorage
- Keyboard support (Enter key)

## Tech Stack
- React
- Vite
- CSS

## How to run locally
npm install
npm run dev
